# 消费争议趋势证据仓

面向监管询证下消费争议证据的**限时保全与交付**后端：联络员先建保全案件、按争议范围冻结材料清单，经业务复核与隐私遮盖批准双门后在法定期限内放行，凭可撤销的授权地址交付，并支持事后抽查核验。技术栈为 Node.js 22、TypeScript、Fastify、Kysely 与 SQLite。

SQLite 数据文件默认位于项目目录的 `data` 下，也可由 `DATABASE_PATH` 指向工作目录内的其他位置；监听端口通过 `PORT` 配置。服务不连接外部数据库、缓存或消息系统。服务启动时自动执行 `migrations/` 下尚未应用的迁移。

执行 `npm run db:migrate` 初始化数据库，`npm test` 运行测试，`npm run build` 编译项目，`npm start` 启动服务。Docker 镜像构建过程中会先执行测试和编译。

## 领域流程

建案（含法定时限）→ 接入材料（同内容去重、异文隔离）→ 冻结清单（稳定摘要）→ 业务复核确认完整 → 制备交付包（字段遮盖 + 缺件说明）→ 隐私专员批准同一版本 → 时限内放行 → 签发/撤销授权下载地址。冻结后的更正、撤回、补件只追加关联事实；法律保全生效后常规清理一律豁免。完整状态机、错误码与接口见 [`docs/domain.md`](docs/domain.md)。

## 开发检查

- 编译或构建：`npm run build`
- 测试：`npm test`
